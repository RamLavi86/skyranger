# Sky Ranger

An open, modular SCADA platform: edge-first, vendor-neutral, built on open standards so customers can always walk away with their data and configuration.

## Status

Early design phase. See [docs/decisions.md](docs/decisions.md) for the decisions made so far.

## Goals

1. Fun and learning.
2. A system deployable by its author as an integrator for a few customers, earning trust through testing and a conservative scope.
3. Long term: a platform other SCADA engineers can build on.

## First milestone

A vertical slice: one real ESP32 water meter plus simulated devices, flowing through a tag engine into history storage and a live web dashboard.
